PORTOFOLIO MOHAMAD FAUZAN — BLACK TITANIUM

ISI PAKET
- index.html: halaman portofolio utama
- certificates/: 6 sertifikat PDF satu halaman + semua sertifikat dalam satu PDF
- images/: pratinjau sertifikat yang tampil di galeri

CARA MEMASANG DI GITHUB PAGES
1. Ekstrak ZIP ini.
2. Buka repositori GitHub: mohamad-fauzan-portfolio.
3. Unggah isi folder paket ini (bukan folder pembungkusnya) ke root repositori.
4. Jika diminta, pilih Replace/Commit changes untuk index.html dan folder images serta certificates.
5. Tunggu GitHub Pages selesai memperbarui, lalu buka https://mhmdfzn01-dot.github.io/mohamad-fauzan-portfolio/

CATATAN
- Jangan mengunggah hanya index.html; folder images dan certificates diperlukan agar gambar dan tautan PDF berfungsi.
- Periksa kembali nama dan tanggal sertifikat sebelum publikasi. Tanggal Google Coursera mengikuti yang terbaca pada sertifikat asli; sertifikat lainnya mengikuti dokumen sumber.
